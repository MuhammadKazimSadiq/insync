# Triage Labels

The five canonical triage roles mapped to this project:

- `needs-triage`: Newly proposed issue awaiting review or categorization.
- `needs-info`: Blocked on missing requirements or technical clarification.
- `ready-for-agent`: Fully specified vertical slice ready for autonomous implementation.
- `ready-for-human`: Requires manual human intervention (e.g., signing keys, OS permission grants, external credentials).
- `wontfix`: Deliberately out of scope or rejected.
